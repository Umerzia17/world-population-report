# User Stories

## User Story 1
As a user, I want to see all countries sorted by population,
So I can compare the population of different countries.

## User Story 2
As a user, I want to see all cities sorted by population,
So I can compare the population of cities around the world.

## User Story 3
As a user, I want to see all capital cities sorted by population,
So I can identify the most populated capital cities.

## User Story 4
As a user, I want to view the top N most populated cities in the world,
So I can focus on the largest cities without viewing the complete list.

## User Story 5
As a user, I want to view the population of each country, including people living in cities and people not living in cities,
So I can understand the distribution of the population within each country.

## User Story 6
As a user, I want to retrieve the population of the world, a continent, a region, a country, a district, or a city,
So I can access population information for different geographical areas.

## User Story 7
As a user, I want to see the number of people who speak Chinese, English, and Spanish, along with the percentage of the world's population,
So I can compare the usage of the most widely spoken languages.


## User Story 8
As a user, I want to view project documentation, screenshots, build instructions, and test evidence,
So I can understand, build, run, and verify the application easily.
